API

WindkesselIdentification — Module

Identification of 2-, 3- and parallel 4-element Windkessel models from measured aortic pressure and flow.

Units throughout: pressure in mmHg, flow in mL/s, time in s, so that Rp, Rc [mmHg s/mL], C [mL/mmHg], L [mmHg s^2/mL].

source

The parameter vector is θ = [Rp, C, Rc, L] (the first three for G3, the first two for G2).

Models

WindkesselIdentification.G — Function
G(θ, h; discretize=true) -> StateSpace

Parallel 4-element Windkessel model (Burattini, Westerhof, Stergiopulos) from aortic flow [mL/s] to aortic pressure [mmHg], as a ControlSystemsBase StateSpace with 2 states.

Arguments

  • θ: parameters [Rp, C, Rc, L]: peripheral resistance Rp [mmHg s/mL], compliance C [mL/mmHg], characteristic resistance Rc [mmHg s/mL], inertance L [mmHg s^2/mL].
  • h: sampling period [s] (ignored when discretize=false).

Keyword arguments

  • discretize=true: if true, return the exact zero-order-hold discretisation with period h; if false, return the continuous-time model.

The state is diagonal: x1 = volume on C [mL], x2 = L times the flow through L [mmHg s].

Examples

julia> sys = G([0.79, 1.22, 0.056, 0.0051], 0.005);

julia> sys.nx, sys.nu, sys.ny
(2, 1, 1)

WindkesselIdentification.G3 — Function
G3(θ, h; discretize=true) -> StateSpace

3-element Windkessel model from aortic flow [mL/s] to aortic pressure [mmHg], with 1 state. Equals the 4-element model G with L = Inf.

Arguments

  • θ: parameters [Rp, C, Rc] with Rp, Rc [mmHg s/mL] and C [mL/mmHg]. Only the first 3 entries are used.
  • h: sampling period [s] (ignored when discretize=false).

Keyword arguments

  • discretize=true: ZOH-discretise with period h if true, else continuous time.

The state x1 is the volume on C [mL].

WindkesselIdentification.G2 — Function
G2(θ, h; discretize=true) -> StateSpace

2-element Windkessel model from aortic flow [mL/s] to aortic pressure [mmHg], with 1 state. Equals the 4-element model G with Rc = 0 (L then has no effect).

Arguments

  • θ: parameters [Rp, C] with Rp [mmHg s/mL] and C [mL/mmHg]. Only the first 2 entries are used.
  • h: sampling period [s] (ignored when discretize=false).

Keyword arguments

  • discretize=true: ZOH-discretise with period h if true, else continuous time.

The state x1 is the volume on C [mL].

WindkesselIdentification.simulate — Function
simulate(θ, x0, u, h; xout=false, G_=G) -> y  or  (y, X)

Simulate the ZOH-discretised model G_(θ, h) with input u from initial state x0.

Arguments

  • θ: parameters [Rp, C, Rc, L] (first 3 for G3, first 2 for G2); Rp, Rc [mmHg s/mL], C [mL/mmHg], L [mmHg s^2/mL].
  • x0: initial state (x1 volume on C [mL]; for G also x2 = L times the flow through L [mmHg s]).
  • u: input vector, aortic flow [mL/s].
  • h: sampling period [s].

Keyword arguments

  • xout=false: also return the state trajectory.
  • G_=G: model, G, G3 or G2.

Returns

  • y: aortic pressure [mmHg], same length as u.
  • X (only if xout=true): length(u) x length(x0) matrix, row k is the state at sample k (before applying u[k]).

WindkesselIdentification.solvex0 — Function
solvex0(sys, u) -> x0

Initial state for which the response to the input u is periodic: x(n) = x(0), with n = length(u). With s the state reached from x(0) = 0 after n steps, x(0) = (I - A^n)^-1 s.

Arguments

  • sys: a discrete-time StateSpace, e.g. G(θ, h), G3(θ, h) or G2(θ, h).
  • u: input vector, aortic flow [mL/s], typically one or more whole beats.

Returns

  • x0: vector of length sys.nx, in the model's state units (x1 volume on C [mL]; for G also x2 = L times the flow through L [mmHg s]).

cost uses this at every evaluation when x0solve=true.

Identification

WindkesselIdentification.identify — Function
identify(θ0, x00, u, y, h; θid=[1,1,1,1], x0id=true, x0solve=false, G_=G, θpos=true, v=false) -> (phat, res)

Estimate a chosen subset of the model parameters θ and the initial state x(0) by minimising cost, the sum of squared output errors, with second-order Optim methods (exact ForwardDiff gradient and Hessian).

Arguments

  • θ0: initial guess [Rp, C, Rc, L] (first 3 for G3, first 2 for G2); Rp, Rc [mmHg s/mL], C [mL/mmHg], L [mmHg s^2/mL]. Entries not marked free in θid stay fixed at these values.
  • x00: initial guess for x(0) (x1 volume on C [mL]; for G also x2 = L times the flow through L [mmHg s]); used as is when x0id=false and x0solve=false.
  • u: input, aortic flow [mL/s].
  • y: measured output, aortic pressure [mmHg], same length as u.
  • h: sampling period [s].

Keyword arguments

  • θid=[1,1,1,1]: 0/1 mask over θ; 1 = estimated, 0 = fixed at θ0. Must have the same length as θ0, so pass e.g. θid=[1,1,1] with G_=G3.
  • x0id=true: also estimate x(0), as extra parameters after the free θ entries.
  • x0solve=false: recompute x(0) at every cost evaluation as the periodic initial state from solvex0, instead of using x00 or estimating it. Use with x0id=false.
  • G_=G: model, G (4-element), G3 or G2.
  • θpos=true: if true, use Optim IPNewton with bounds θ >= 0 on the free θ entries (x(0) unbounded); if false, use unconstrained Newton with a backtracking line search.
  • v=false: show the Optim trace.

Returns

  • phat: estimated optimisation vector: the free θ entries (in order), then x(0) if x0id. Use WindkesselIdentification.deal(phat, IdConditions(θ0, x00, θid, x0id, x0solve, G_)) to get the full (θ, x0) back.
  • res: the Optim result. res.minimum is the sum of squared errors [mmHg^2]; divide by length(u) for the MSE.

See also identifyglobal.

source
WindkesselIdentification.identifyglobal — Function
identifyglobal(θ0, x00, u, y, h; θid=[1,1,1,1], x0id=true, x0solve=false, G_=G, v=false) -> (phat, res)

Same problem as identify, solved with the derivative-free Optim NelderMead (up to 1e5 iterations). Less sensitive to the initial guess, but slower.

The search is unconstrained: unlike identify with θpos=true there is no positivity constraint on θ, so check the signs of the estimate.

Arguments, keyword arguments and returns are as for identify (there is no θpos). Get (θ, x0) with WindkesselIdentification.deal(phat, IdConditions(...)); res.minimum is the sum of squared errors [mmHg^2].

source
WindkesselIdentification.cost — Function
cost(p, id::IdConditions, u, y, h) -> Real

Sum of squared output errors sum((y - yhat).^2) [mmHg^2] of the model id.G_, ZOH-discretised with period h, driven by u. This is the objective minimised by identify and identifyglobal.

Arguments

  • p: optimisation vector: the free entries of θ (where id.θid is 1, in order), followed by x(0) if id.x0id. Build it with WindkesselIdentification.p(θ, x0, id).
  • id: IdConditions; fixed θ entries and (unless x0id) x(0) come from it. If id.x0solve, x(0) is instead computed with solvex0.
  • u: input, aortic flow [mL/s].
  • y: measured output, aortic pressure [mmHg], same length as u.
  • h: sampling period [s].

Divide by length(u) for the mean squared error.

WindkesselIdentification.IdConditions — Type
IdConditions(θ0, x00, θid, x0id, x0solve, G_=G)

Identification setup: which parameters are free, their fixed or initial values, and the model. Built internally by identify and identifyglobal; construct it yourself to call cost or WindkesselIdentification.deal.

Fields

  • θ0::Vector{Float64}: model parameters [Rp, C, Rc, L] (first 3 for G3, first 2 for G2); Rp, Rc [mmHg s/mL], C [mL/mmHg], L [mmHg s^2/mL]. Initial guess for free entries, fixed value for the others.
  • x00::Vector{Float64}: initial state x(0) (x1 volume on C [mL]; for G also x2 = L times the flow through L [mmHg s]). Initial guess if x0id, else fixed.
  • θid::Vector{Int}: 0/1 mask, same length as θ0; 1 marks a free (estimated) entry, 0 keeps it fixed at θ0. E.g. [1,1,1,0] fixes L.
  • x0id::Bool: estimate the initial state as extra parameters.
  • x0solve::Bool: recompute x(0) from periodicity with solvex0 at every cost evaluation (use with x0id=false).
  • G_::Function: model constructor, G, G3 or G2.

The 5-argument constructor sets G_ = G. Throws an error if length(θ0) != length(θid).

source
WindkesselIdentification.p — Function
WindkesselIdentification.p(θ, x0, id::IdConditions) -> Vector{Float64}

Build the optimisation vector from the full parametrisation: the entries of θ where id.θid is 1 (in order), followed by x0 if id.x0id. Inverse of WindkesselIdentification.deal. Not exported.

source
WindkesselIdentification.deal — Function
WindkesselIdentification.deal(p, id::IdConditions) -> (θ, x0)

Map an optimisation vector p (e.g. phat from identify) back to the full parametrisation: free θ entries are taken from p, fixed ones from id.θ0; x0 is taken from p if id.x0id, else it is id.x00. Inverse of WindkesselIdentification.p. Not exported.

Note: with x0solve=true the returned x0 is id.x00, not the periodic state used in the cost; recompute it with solvex0.

WindkesselIdentification.load_stergiopulos1999 — Function
load_stergiopulos1999() -> (p, q, h)

One type A beat from Stergiopulos et al. (1999), Figure 4A, digitised at 200 Hz: aortic pressure p [mmHg] and flow q [mL/s], sampling period h [s].

source
WindkesselIdentification.load_pig — Function
load_pig(source::Symbol; segments=1:4) -> (p, q, h)

Aortic pressure p [mmHg] and flow q [mL/s] from 65 kg pigs, source = :invivo (2020-12-01) or :exvivo (a different heart beating against a synthetic afterload, 2020-12-02). The recording is split in four contiguous segments; segments picks which to concatenate. The raw files store flow in L/min; it is converted here. Sampling period h = 5 ms.

source
WindkesselIdentification.params_stergiopulos1999total — Function
params_stergiopulos1999total() -> (θ, x0)

Reference parameters of the 4-element model from Stergiopulos et al. (1999), Table 1, type A beat, for use with load_stergiopulos1999.

Returns

  • θ = [Rp, C, Rc, L] = [0.79, 1.22, 0.056, 0.0051]: Rp, Rc [mmHg s/mL], C [mL/mmHg], L [mmHg s^2/mL].
